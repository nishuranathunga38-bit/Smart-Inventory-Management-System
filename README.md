# Smart Inventory Management System

An AI-assisted web-based inventory management system designed to help businesses manage products, stock, sales, and inventory-related activities efficiently.

## 🚀 Key Features

- Product and inventory management
- Stock monitoring
- Sales management
- User-friendly web interface
- Database management
- AI-assisted inventory analysis
- Predictive analytics
- Admin management features

## 🛠️ Technologies Used

- Java
- JSP
- Servlets
- Python Flask
- MySQL
- Bootstrap
- HTML
- CSS
- JavaScript

## 🤖 AI Features

The system includes AI-assisted functionality to support inventory analysis and predictive insights, helping users make better inventory-related decisions.

## 🏗️ Project Architecture

The main web application is developed using Java, JSP, and Servlets, while Python Flask is used as an AI microservice. MySQL is used for database management.

## 💻 Development Tools

- Apache NetBeans
- XAMPP
- MySQL Workbench
- Apache Tomcat

## 🎓 Project Purpose

This project was developed as an academic project to apply practical knowledge in web application development, database management, and AI-assisted software solutions.
